# 小小学习岛 · GitHub Pages

访问：https://yiersisan.github.io/pwatest/

当前发布：`v37-home-task-flow`。

此分支为静态发布产物，只包含运行文件与界面素材，不包含开发依赖、测试页、演示视频或用户数据。开发工作区仍保留完整源码、测试与产品文档。

原生 HTML/CSS/JavaScript 单页 PWA，无业务后端。课程与学习记录保存在浏览器 IndexedDB，视频文件只用于当前会话，可导出业务数据。今日任务默认每门课程取第一个没看过的视频；内容中心仅展示有视频的课程；首页定制有家长计算题验证。保存首页配置成功返回首页。

发布前 64/64 项测试通过，完成三种 iPad 尺寸浏览器检查，未做 iPad 真机验证。发布文件的 Git blob 校验值见 `release.json`。
