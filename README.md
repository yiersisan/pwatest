# 我的备忘录 PWA

无构建步骤的静态网页，支持 iPad 添加到主屏幕及离线备忘录。

## GitHub Pages

将仓库的 `main` 分支作为发布来源，目录选择 `/ (root)`，使用 HTTPS 访问。
所有页面、清单、图标和 Service Worker 路径均兼容仓库子目录。

## iPad 使用

在 Safari 中联网打开网站，等页面显示“离线准备完成”，再通过分享菜单添加到主屏幕。
若系统提供“作为网页 App 打开”，请开启它。已安装的旧图标可能需要移除主屏幕入口后重新添加。
备忘录仅保存在当前设备，不会通过 GitHub 同步。

## 缓存策略

- 首次安装同时预缓存根地址和 `index.html`，支持两种入口离线访问。
- 页面及图标采用网络优先，断网或服务器错误时回退缓存。
- 成功获取页面后，同步更新根地址与 `index.html` 两个缓存入口。
- 发布新版本时递增 `sw.js` 中的缓存版本；只清理当前部署路径的旧缓存。
- 网站缓存不包含第三方网站、网盘或视频。视频离线下载尚未实现。

## 验证

需要 Node.js 18 或更新版本：

```sh
node --test tests/sw.test.cjs
```

测试覆盖离线入口、新内容更新、服务器错误回退、缓存隔离、存储失败、请求范围和图标尺寸。
这是逻辑测试，仍需在 iPad 真机验证安装及飞行模式下重新打开。
