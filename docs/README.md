## 后续维护约定

1. 同一功能的调整优先更新已有文档；新主题使用 `NN-topic.md` 命名，并在上表添加链接。
2. 实现说明写清对应源码、关键流程、选择原因、限制和验证方法。
3. 行为发生变化时更新对应文档；值得保留的旧方案及其替换原因记入文档 04。
4. 区分源码实现、自动化测试、网络探测和用户真机反馈，不把其中一种当成其他方式的验证结果。
5. 文档示例使用占位 URL，不重复收录签名或登录信息。此次默认测试清单的公开授权与范围单独记在文档 07。
